## The one rule that matters most

**Discord is not the GDD.** A decision made in chat or voice does not exist until it is written into `GDD.md` and linked in the relevant channel. Pin the link.

## Definition of Done — five gates

A task is done only when **all five** pass:

1. **Logic** — behaviour works, edge cases handled
2. **Visual** — final-style art/VFX present, no grey cubes
3. **Audio** — cue from `GDD.md` §6 plays at the right moment
4. **UX** — legible at target resolution; state communicated without text
5. **Build** — confirmed in the sprint build, not just in the editor
